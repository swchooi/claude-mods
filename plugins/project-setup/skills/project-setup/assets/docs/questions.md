# Questions

What the owner needs to decide. Numbered `Q-NNN`, never renumbered.

Each open question has the options, a recommendation, and what changes with
each answer. The agent may write a **Proposal:** under a question but never
ticks it: only the owner answers. When answered, record the answer where it
belongs (a decision, or the doc it affects), tick it, and move it to
**Answered** with a pointer.
