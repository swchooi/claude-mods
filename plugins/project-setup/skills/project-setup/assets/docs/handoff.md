# Handoff

What recent sessions did and where they stopped. **Newest first.** Add an entry
at the end of every session, including ones that only asked questions. Keep the
10 newest; move older ones to `archive/handoff-YYYY.md` after checking their
durable lessons reached `architecture/gotchas.md`.

## Template

```markdown
## YYYY-MM-DD · <short title>

- **Goal:** what this session set out to do (task / milestone ID)
- **Done:** what changed, with PR or commit links
- **Stopped at:** exactly where, and the next concrete step
- **Watch out:** what bit, what's fragile, what's unverified
- **Questions raised:** Q-NNN (and the provisional default taken)
- **Docs changed:** structural changes, new or archived files
```
